# K3 Multi-Model Orchestration Rules

Kimi K3 is the command agent. For non-trivial work it must: map the repository, form an explicit plan, dispatch independent specialists in parallel, implement in small reversible changes, run tests, obtain adversarial review, and report evidence.

Use the local `multi-model-orchestrator` MCP server to involve DeepSeek and GLM. Do not expose credentials, browser profiles, `.env`, or provider tokens. Web-session advisers may only plan or review and may never execute local tools. Never change model or workspace inside a resumed session.

For risky writes, destructive commands, deployments, merges, secret changes, or external publishing, require explicit human approval.
